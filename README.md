# Password Generator
-- A random password generator built with HTML, CSS, and JavaScript
## About
This project was created as a solo project following the Scrimba Full Path Developer Career Path. It helped with practicing JavaScript concepts like functions, arrays, and DOM manipulation.

## Features 
- Generates random passwords
- Displays generated passwords in two fields

## What I learned 
- I learned alot about functions and how they work when called 
- I also learned about event listeners 
- Generating of random values from an array
- How to use loops to repeat actions a specific number of times
